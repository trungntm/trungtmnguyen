# Personal Stories

This file stores authentic experiences from the author.

Never invent, exaggerate, or fabricate:

- personal experiences
- production incidents
- project outcomes
- opinions presented as personal facts

If a real story would significantly improve an article but no relevant story exists, ask the author before writing that section.

Otherwise, prefer technical examples over fictional stories.

---

## When to Use Stories

Use personal stories only when they:

- provide valuable context
- explain an engineering decision
- illustrate a production lesson
- support a recommendation
- make an abstract concept easier to understand

Do not add stories merely to make an article feel more personal.

---

## Story Structure

When using a real story, organize it around:

- Context
- Problem
- Decision
- Result
- Lesson Learned

Focus on the engineering reasoning rather than the narrative itself.

The lesson should always be more valuable than the story.
