# Preferred Terminology

Prefer the following terminology unless context requires otherwise.

| Prefer               | Instead of                                                 |
| -------------------- | ---------------------------------------------------------- |
| software engineer    | programmer                                                 |
| backend              | server-side                                                |
| frontend             | client-side                                                |
| tradeoff             | pros and cons                                              |
| engineering decision | choice                                                     |
| production           | real-world                                                 |
| implementation       | coding                                                     |
| architecture         | system design (when referring to overall system structure) |

Use terminology consistently throughout an article.

Avoid switching between synonyms unnecessarily.

When an industry-standard term exists, prefer the industry-standard term.
